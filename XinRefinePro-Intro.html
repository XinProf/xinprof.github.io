概览 / Overview

不是把曲线画上去，
而是让模型与整条谱对齐

全谱拟合的价值，在于让结构模型同时解释每一个峰、每一段背景与每一处重叠。XinRefinePro 把这件事拆成可检查的步骤：参数从哪里开始、何时收敛、R 因子如何变化，都留在工程与报告里。

  • 可检查每一步都有参数快照、收敛状态与 R 因子对照。
  • 可复现同一份谱图与结构，得到同一条计算曲线。
  • 可交付定量、e.s.d. 与约束声明一起进入报告。

两种多谱策略 / Multi-pattern

同一组数据，两种收敛方式

温度序列、时间序列、多探测器或多次装样——多谱数据要回答的问题不同，精修策略也不该只有一种。

01

序贯精修

逐谱推进，把上一谱的结构作为下一谱的起点。

  • 每一谱独立收敛背景、标度与峰形
  • 结构参数热启动到下一谱，减少发散
  • 逐谱 Rwp 并列对照，演化趋势一眼可见
  • 可选并行求解，批量序列更快完成
谱 1 → 谱 2 → 谱 3 → …
02

联合精修

所有谱共享一套结构参数，按全局分母计算 R 因子。

  • 结构参数在全部谱图之间共享
  • 全局 R 因子避免逐谱平均造成的误判
  • 弱峰在多谱中得到更稳的统计支撑
  • 适合多探测器、多条件数据的合并分析
谱 1 + 谱 2 + 谱 3 → 共享结构
怎么选？看结构是否应该一致。同一批样品在不同温度或时间下连续演化，用序贯；多组独立数据需要一套共同结构，用联合。两种模式都同时给出逐谱 Rwp 与全局 R 因子，口径不混。

精修流程 / Workflow

八步标准配方，一键连跑

从谱参数到微结构，按推荐顺序逐步放开参数。每一步可以单独执行、单独检查；也可以一键连跑，坐等收敛。

  1. 01

    零点 / 样品漂移

    校正装样高度与仪器零点，先让峰位对齐。

  2. 02

    背景 + 峰形

    同时收敛背景与峰形，给后续参数一个干净基线。

  3. 03

    标度因子

    调整各相与各谱的绝对强度比例。

  4. 04

    晶胞参数

    精修 a / b / c / α / β / γ，让峰位与结构一致。

  5. 05

    峰形参数

    放开 U / V / W 与峰形混合，匹配仪器与样品宽化。

  6. 06

    原子坐标

    在结构允许时精修原子位置，改善结构因子。

  7. 07

    温度因子

    收敛原子位移参数，描述热振动与占位。

  8. 08

    微结构 / 应力 / 择优取向

    处理晶粒尺寸、微观应变与择优取向。

可单步 可连跑 Rwp 前后对照

每一步结束都会留下 Rwp 变化，收敛与回退都能看见。

高阶能力 / Capabilities

十八项能力，按需开启

不是“全部默认打开”的黑箱。每项能力都有明确的适用场景与前置关系，组合不成立时会在计算开始前提示。

①

序贯多谱精修

逐谱精修并热启动结构，适合温度与时间序列。

②

联合多谱精修

共享结构、全局分母 R 因子，适合合并多组数据。

③

硬约束

等式、线性与耦合约束，每步投影回可行域；冲突可回滚。

④

软约束

约束声明与校验；未参与求解时如实标注，不伪装生效。

⑤

仪器参数文件

导入仪器峰形与分辨率参数，统一仪器贡献。

⑥

各向异性宽化

晶粒尺寸与应变随方向变化，Popa 模型描述。

⑦

球谐织构

以 4–10 阶球谐描述择优取向，适合压制样品。

⑧

非晶宽包 / 内标

非晶相宽包与内标定量，处理部分结晶样品。

⑨

Brindley 微吸收

校正颗粒微吸收对衍射强度的影响。

⑩

U_ij 原子位移

各向异性原子位移参数进入结构因子。

⑪

消光 / 透射

校正强吸收、大晶粒样品的强度损失。

⑫

中子衍射

以散射长度替代 X 射线散射因子，适配中子数据。

⑬

FCJ 不对称

低角度峰形不对称的经验校正。

⑭

反常散射

f′ / f″ 修正，让近吸收边数据更可靠。

⑮

偏振

同步辐射偏振条件下的强度校正。

⑯

扩展几何

⑰

并行加速

多谱并行求解，批量任务更快完成。
